# Sample client request

**Title:** Change login button colour

**Description:** Please change the login button from green to blue because the current colour does not match our company's branding.

**Expected triage characteristics (illustrative):**
- Classification: actionable, if the project context makes the target button clear.
- Priority: Low (cosmetic change).
- Component/category: should be inferred only if supported by project documentation.
- Acceptance criteria: should be testable and limited to the requested colour change.
