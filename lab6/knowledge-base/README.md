# Knowledge base

The two supplied blueprints do not contain a separate project knowledge-base document or attached reference files. This folder is reserved for project-specific documentation you choose to add.

Suggested files:
- `project-context.md`: project purpose, supported products, users and technology stack.
- `components.md`: authoritative component/module names and their responsibilities.
- `business-rules.md`: domain-specific constraints and terminology.

Do not add client secrets, personal data, credentials or private submissions to a public repository.
