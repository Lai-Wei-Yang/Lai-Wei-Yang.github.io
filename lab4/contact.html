Soalan Lazim untuk Majikan & Perekrut

Jawapan pantas mengenai jadual akademik UKM, kepakaran teknologi, dan kebolehcapaian kerja bagi calon latihan industri.

1

Bilakah tarikh ketersediaan bagi penempatan latihan industri (internship)?

Kemasukan latihan industri rasmi mengikut kalendar akademik FTSM UKM adalah bagi Sesi 2025. Tempoh penempatan boleh diselaraskan selama 24 minggu (6 bulan) mengikut piawaian fakulti dan syarat penajaan syarikat anda.

event_available Ketersediaan disahkan: Sesi 2025
2

Apakah bahasa pengaturcaraan dan teknologi yang paling anda selesa gunakan?

Mahir dalam Java, Python, JavaScript, dan Kotlin. Untuk ekosistem web dan mudah alih, saya kerap membina sistem berasaskan React, Node.js, Tailwind CSS, Flask, serta Jetpack Compose dengan sokongan pangkalan data MySQL dan MongoDB.
Java Kotlin React Node.js MySQL
3

Adakah anda bersedia bekerja di luar kawasan Bangi / secara hibrid?

Ya, sepenuhnya. Saya sangat fleksibel untuk beroperasi di kawasan Lembah Klang (Kuala Lumpur, Cyberjaya, Putrajaya, Petaling Jaya) mahupun di seluruh Semenanjung Malaysia, sama ada dalam mod kerja di pejabat (on-site), hibrid, atau jarak jauh (remote).

explore Kawasan Keutamaan: Lembah Klang & Seluruh Malaysia
4

Bagaimanakah cara untuk menyemak kod sumber projek-projek anda?

Semua projek akademik dan inisiatif peribadi didokumenkan secara telus dalam repositori awam saya. Anda boleh meneliti commit history, architecture diagram, dan struktur kod dengan terus melayari laman rasmi saya di GitHub.
