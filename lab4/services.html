Software Engineering Intern

Web Application Developer Intern

Mobile Application Developer Intern (Android)

Pembangunan aplikasi mudah alih Android berasaskan bahasa Kotlin, reka bentuk antara muka pengguna moden menggunakan kerangka deklaratif Jetpack Compose, serta penyelarasan data tempatan (local caching) dan penyepaduan servis luaran.

Kotlin Jetpack Compose Android Studio Mobile UX
