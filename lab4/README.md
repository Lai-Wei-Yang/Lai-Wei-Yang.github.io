# Lab 4 — UKM Software Engineering Portfolio

## Struktur
- `index.html` — halaman utama portfolio Lab 4
- `about.html` — latar belakang dan kemahiran
- `portfolio.html` — projek dan portfolio
- `services.html` — servis dan minat kerjaya
- `contact.html` — halaman hubungi
- `assets/` — CV teks dan tangkap layar rujukan Stitch

## Integrasi dengan direktori semua makmal
Letakkan folder `lab4/` sebaris dengan folder `lab1/`, `lab2/`, `lab3/` dan fail `index.html` direktori utama.
Direktori utama perlu memaut ke `lab4/index.html`.
