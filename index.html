Reflection: This lab provided my first experience with Jetpack Compose, teaching me how to structure basic layouts using Composable functions. I learned the fundamental importance of UI hierarchy.

Lab 2: Interaction

Description: Implementing user interactions and basic state management.

Reflection: During this session, I moved beyond static screens to implement user interactions and button triggers. I learned how to manage simple state changes.

Lab 3: Material Design

Description: Applying Material Design components, theming and accessibility.

Reflection: This lab focused on applying Material Design components to ensure my app followed professional styling and accessibility standards.

Lab 4: Navigation

Description: Multi-screen navigation and passing data between composables.

Reflection: This was a crucial step in understanding how to link multiple screens into a seamless flow, transitioning from an isolated screen to a multi-screen application.

Lab 5: Room Database

Description: Local persistence with Room database for offline-first apps.

Reflection: I integrated local data persistence, allowing the app to store and retrieve user-generated data permanently even after a restart.

📝 Learning Journey

I have evolved from building basic UI layouts in Jetpack Compose to orchestrating complex, hardware-aware mobile applications that integrate Room persistence, Firebase cloud storage, and live REST API data. This progression challenged me to move beyond static interfaces and deeply understand the lifecycle of data and sensors, transforming my initial SDG concept into a functional, real-world solution. Through these assignments, I have gained confidence in debugging technical architecture and learned that effective mobile development relies as much on systematic problem-solving as it does on creative design.
