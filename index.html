📘 Labs

Lab 1: UI Fundamentals

Description: First steps with Jetpack Compose layouts and composable functions.

Reflection: This lab provided my first experience with Jetpack Compose, teaching me how to structure basic layouts using Composable functions. I learned the fundamental importance of UI hierarchy and how to build simple, visual representations of my SDG theme.

Lab 2: Interaction

Description: Implementing user interactions and basic state management.

Reflection: During this session, I moved beyond static screens to implement user interactions and button triggers. I learned how to manage simple state changes, which served as the essential building block for making my application responsive to user input.

Lab 3: Material Design

Description: Applying Material Design components, theming and accessibility.

Reflection: This lab focused on applying Material Design components to ensure my app followed professional styling and accessibility standards. I learned how to use themes, color schemes, and standardized UI elements to significantly improve the user experience and visual consistency.

Lab 4: Navigation

Description: Multi-screen navigation and passing data between composables.

Reflection: This was a crucial step in understanding how to link multiple screens into a seamless flow, transitioning from an isolated screen to a multi-screen application. I learned to use the Navigation component to pass data between screens, creating a logical user journey that supports my SDG project.

Lab 5: Room Database

Description: Local persistence with Room database for offline-first apps.

Reflection: In this lab, I integrated local data persistence, allowing the app to store and retrieve user-generated data permanently even after a restart. I learned how to set up the Room database architecture, which was essential for transitioning my app from a prototype into a data-driven tool.

I have evolved from building basic UI layouts in Jetpack Compose to orchestrating complex, hardware-aware mobile applications that integrate Room persistence, Firebase cloud storage, and live REST API data.
